A7. win_counter

## описание анимаций
### A1.
- Барабаны стартуют слева направо с шагом 80мс. 
- В начале анимации откат вверх на 8-12px за 120мс (разгон).
- Далее вращаются как в слотах сверху вниз.
- На скорости размытие (80%) по вертикали.
- в этом состоянии зацикливаются пока не начнется следующая анимация.

### A2.
- Барабаны останавливаются слева направо с шагом 160мс.
- отскок вниз на 10px за 150мс easeOutBack.
- в результате анимации на поле показаны символы из ответа /api/play

### A3.
- выигрышные символы пульсируют (scale 1 -> 1.12 -> 1) тайминг 400мс
- рисуется линия и сумма линии
- несколько линий показываются по очереди 1.2с на линию, затем общий итог.

### A4,A5,A6
- порог от общей ставки: big_win >=20x, mega_win >= 40x, epic_win >= 80x
- анимация счётчика (A7) для big - 3с, mega - 5с, epic - 8с
- на пороге следующего уровня заголовок смёняется со вспышкой
- вылетают частицы монет
- первый клик по экрану доводит счётчик до конца
- второй клик закрывает экран

### A7.
- сумма в панели выигрыша растёт от 0 до totalWin за 600мс.
- баланс обновляется только после завершения анимации.

## Уточнения
- экраны и ассеты для Big, Mega, Epic win уже есть в проекте
- анимации можно пропускать кликом ЛКМ или пробел.

## tech
- используй GSAP и таймлайны
- создай модуль/сущность animationController в которой будет описана вся логика анимаций и таймлайны. Эта сущность ответственна за игровые анимации.

## flow
- игрок нажимает spin
- система делает запрос на /api/play
- пока система ожидает ответ - запускается анимация start_spin (A1). Барабаны начинают вращаться. минимальное время вращения 900мс.
- система получает ответ от /api/play и узнает массив events и finalState. В этот момент анимация A1 переходит в анимацию stop_spin (A2). Барабаны заканчивают вращение а состояние поля соответствует reveal
- Анимация A2 переходит в анимацию A3. Когда барабаны остановились подсвечиваются выигрышные символы, рисуются линии.
- Вместе с анимацией A3 выполняется анимация A7. Растет сумма выигрыша игрока.После завершения анимаций обновляется баланс.

## Check
- обычный spin без выигрыша
- spin с одной выигрышной линией
- spin с несколькими линиями
- Big win >=20x
- Mega win >=40x
- Epic win >=80x
- быстрый ответ API
- медленный ответ API
- skip мышью
- skip пробелом
- повторный spin после завершения
- отсутствие утечек таймлайнов/listeners
