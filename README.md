## getting started
### Локальная разработка

1. Вызвать в терминале команду: `npm i`, чтобы установить зависимости проекта
2. Вызвать в терминале команду: `npm run dev`, чтобы запустить проект локально

### CI/CD
- стандартный next.js CI/CD
- чтобы собрать приложение нужно вызвать команду `npm run build`. В папке .next будут лежать файлы сборки

### deploy
- деплой на платформе vercel в интеграции с github
- public/math - рассчитаный RNG для фронтенда с использованием Stake math-sdk. Кластерный тип.
- public/assets - игровые ассеты pixi после оптимизации assetpack

## Стек технологий
- Стек технологий: Next.js, tailwindcss, pixi.js, GSAP, AssetPack
- Детали архитектуры указаны в `.agents/docs/architecture.md`

## Геймплей и замысел анимаций
- кластерный тип
- wild может объединять кластеры
- risk all экран с риском x2 или x0 (50%/50%)
- Возможность получить награды от Prophecy (x5 final multiplier или 10 FS)
- 3+ специальных символа на поле запускают особый режим:
  - Sun - бонус режим колесо фортуны - возможность выиграть FS.
  - Tower - принудительный запуск риск игры (возможность удвоить текущий выигрыш или проиграть всё)
  - Prophecy - запуск шара предсказаний (возможность выиграть x5 к финальному выигрышу или 10FS)
- обычные символы: swords, wands, star, cups, pentagram
- На поле могут выпасть мультипликаторы: X2, X5, X20, X50, X100. Мультипликатор применяется к прилегающему кластеру

Детальное описание правил игры и гемплейных решений в файле `.agents/docs/game-rules.md`

- Карты на поле при старте лежат рубашкой вверх
- Спин - карты переворачиваются и игрок видит выигрышные кластеры (подсветка)
- В случае бонусных режимов:
  - Для каждого режима свой фон
  - иерархия режимов (в случае одновременного выпадения) Prophecy -> Sun -> Tower
- Шар prophecy - взрыв - осколки - результат
- Башня Tower - смена фона -> fadeIn две карты -> выбор игрока:
  - выигрыш - total win x2, режим выключается -> возврат к стартовому состоянию
  - проигрыш - total win x0, молния бъет в башню -> башня разрушена -> delay 500ms -> возврат к стартовому состоянию
- модалки открываются fadeIn, закрываются fadeOut -> 300ms
- кнопка spin -> при запуске вращение 360deg 100ms
- Новый раунд - текущие карты перевернулись рубашкой вверх 200ms -> delay 200ms -> карты открылись 200ms
- Возможность ускоренных анимаций
- возможность скип анимаций

Дизайн и анимации описаны в файле `/agents/docs/design-guidelines.md`
